# Herkunft der Dateien in diesem Ordner

Trag hier zu JEDER Datei ein, woher sie kommt — vor allem bei KI-generierten
Bildern, damit ein Ersatz/Nachfolger später mit demselben Ansatz erstellt
werden kann, ohne raten zu müssen.

Format-Vorschlag pro Eintrag:

---

**Dateiname:** logo.png
**Erstellt am:** TT.MM.JJJJ
**Erstellt mit:** z. B. Claude Design / DALL-E / eigenes Foto / …
**Prompt/Anweisung (falls KI-generiert):** wörtlich, damit reproduzierbar
**Verwendet für:** z. B. embodiment: "logo" (siehe pictureSrc in
frontend/conversation.js)
**Lizenz/Rechte:** z. B. "eigene Erstellung, keine Einschränkung" oder
Quellenangabe, falls übernommen

---

(Eintrag hier duplizieren für jede weitere Datei in diesem Ordner.)
